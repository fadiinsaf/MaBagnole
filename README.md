# 🚗 MaBagnole - Plateforme de Location de Voitures

## 📋 Description du Projet

MaBagnole est une application web complète permettant de gérer la location de véhicules. Développée avec **PHP (Programmation Orientée Objet)** et **MySQL**, cette plateforme offre deux espaces distincts : un espace client pour réserver des voitures et un espace administrateur pour gérer le parc automobile.

## ✨ Fonctionnalités Principales

### 👤 **Pour les Clients**
- **Inscription et connexion** sécurisée
- **Parcourir le catalogue** de véhicules par catégories
- **Rechercher et filtrer** des voitures selon différents critères
- **Voir les détails** complets de chaque véhicule
- **Réserver une voiture** avec choix des dates et options
- **Donner son avis** sur les véhicules loués
- **Gérer ses réservations** et favoris
- **Pagination** pour naviguer facilement dans les résultats

### 👨‍💼 **Pour les Administrateurs**
- **Tableau de bord** avec statistiques
- **Gérer le parc automobile** (ajouter, modifier, supprimer des véhicules)
- **Gérer les catégories** de voitures
- **Valider ou refuser** les réservations
- **Gérer les avis** des clients
- **Importer plusieurs véhicules** en une seule fois
- **Suivre toutes les locations** en cours et passées

## 🛠️ **Technologies Utilisées**

- **Backend** : PHP 7.4+ avec architecture MVC
- **Base de données** : MySQL avec procédures stockées
- **Frontend** : HTML, CSS, JavaScript
- **Framework CSS** : TailwindCSS pour un design moderne
- **Serveur** : Apache ou Nginx

## 🏗️ **Architecture**

L'application suit le pattern **MVC (Modèle-Vue-Contrôleur)** :
- **Modèles** : Gèrent les données et la logique métier
- **Vues** : Affichent l'interface utilisateur
- **Contrôleurs** : Traitent les requêtes et coordonnent les actions

## 📊 **Base de Données**

La base de données comprend plusieurs tables :
- **Utilisateurs** : Clients et administrateurs
- **Véhicules** : Informations sur les voitures disponibles
- **Catégories** : Types de véhicules (économique, SUV, luxe...)
- **Réservations** : Détails des locations
- **Avis** : Notes et commentaires des clients
- **Options** : Suppléments (GPS, siège enfant...)

## 🚀 **Installation Rapide**

1. **Télécharger** les fichiers du projet
2. **Configurer** un serveur web (Apache/Nginx) avec PHP
3. **Créer la base de données** MySQL
4. **Importer** le fichier SQL fourni
5. **Configurer** les paramètres de connexion
6. **Accéder** à l'application via le navigateur
